# 0005 — 允许中文名称，并收紧 Worktree 创建面板

日期: 2026-11-03
状态: 已接受

## 背景

0002 把创建入口放在分支列表下面，名称框旁边还有基线说明、字符规则和工作区标题预览。分支一多，分隔线会切进最后一行，说明把面板撑成一张表单。环境 chip 还会把已填名称拼在「Worktree」后面，和输入框重复。

名称原先只允许 ASCII 字母、数字和少量符号。分支名、目录名、工作区标题是同一个字符串，中文更好认，但校验会直接拒绝。

## 决策

**名称允许中文。** 同一段文字同时作为新分支名、`<仓库根>/.agents/worktrees/<名称>` 的目录段，以及 Workspace 标题。字母（含中文）、数字，以及 `.`、`_`、`-`、`/` 可用。空格、表情和其他符号拒绝；不能以符号开头或结尾，也不能包含 `..`、`//` 或 `@{`。名称里的 `/` 仍是分支层级，目录段里压成 `-`（同 0003）。

**环境 chip 只显示「Worktree」。** 不再附加已填名称或「自动命名」。名称只出现在分支面板的输入框里。

**创建区钉在列表下方，只留输入和按钮。** 分支列表单独滚动，底栏与搜索框左右对齐。占位符为「请输入 Worktree 名称」。基线说明、字符规则和标题预览不再常驻；不合法、过长、重名时才显示一行错误。自动短码模式没有输入框，只留「创建并进入」。本机模式的分支列表不改。

- 被否决：继续用示例名（如 `登录修复`）当占位符（看起来像已经填过）；把字符白名单写进常驻说明（面板又被撑高）。
- 代价：含空格的中文名不能用，需要写成连续的词。

## 影响

- 正面：列表和创建区分开；chip 不再重复名称；中文名在分支、目录和侧栏标题上一致，便于分辨。
- 负面：桌面端要重启 profile 后才会加载新的宿主校验；已有 worktree 的名字不会自动改。
- 验证：`登录修复` 可通过校验，并创建出同名分支、目录和标题；带空格或表情的名字被拒绝。
